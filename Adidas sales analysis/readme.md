# 📊 Adidas Sales Analysis Dashboard – Power BI


A fully interactive **Power BI dashboard** analyzing Adidas sales performance across products, retailers, regions, and time. This project surfaces actionable insights on revenue, profitability, seasonality, and channel performance.



## 🚀 Project Overview

This dashboard visualizes and analyzes ~**$900M** in sales across **2M units**, offering:

- KPI tiles: Total Sales, Total Profit, Units Sold, Avg Margin, Avg Price/unit  
- Trend analysis: Monthly sales and daily sales patterns  
- Product performance: Sales by product category & model  
- Channel performance: Sales by retailer  
- Geographic analysis: State & regional sales distribution  
- Profitability analysis: Average margin and price insights

Purpose: help stakeholders optimize inventory, promotions, and channel strategy.

---

## 📈 Key Insights

### 1. Overall Performance
- **Total Sales:** $900M  
- **Total Profit:** $332.1M  
- **Units Sold:** 2M  
- **Average Margin:** 36.91%  
- **Average Price / Unit:** $45.2

### 2. Monthly Sales Trends
- **Peak months:** July ($95M), August ($92M), December ($86M)  
- **Lowest month:** March ($57M)  
Seasonal demand spikes mid-year and at year-end.

### 3. Daily Sales Trends
- **Highest day:** Friday ($147M)  
- **Lowest day:** Monday ($112M)  
End-of-week shopping drives top-line.

### 4. Top Product Categories
- Men’s Streetwear  
- Women’s Apparel  
- Men’s Athletic Wear  
Apparel categories dominate revenue.

### 5. Regional Distribution
- **West:** 30%  
- **Northeast:** 21%  
- **Southeast:** 18%  
- **South:** 16%  
- **Midwest:** 15%  
West region is the primary market.

### 6. Top Retailers
- West Gear  
- Foot Locker  
- Sports Direct  
- Kohl’s  
- Amazon  
Retail partners are key revenue channels.

### 7. State-Level Observations
Sales concentrated in western and northeastern states; map visual highlights distribution.

## 📝 How to Use (Quick)

1. Clone or download the repo.  
2. Open `Adidas_Sales.pbix` in Power BI Desktop.  
3. If map tiles appear blank, ensure internet access and enable privacy settings:  
   `File → Options and settings → Options → Privacy → Always ignore privacy settings`.  
4. Refresh dataset or replace `Dataset.csv` then click **Refresh** in Power BI.
