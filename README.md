# 📊 Power BI Projects by Pankaj Kumar Yadav

This repository contains a collection of interactive and business-focused **Power BI dashboards** created using real-world datasets.  
Each project demonstrates data modelling, DAX calculations, visualization best practices, and actionable business insights.

---

## 📂 Projects Included

### 🔹 Adidas Sales Analysis  
Sales trends, top products, region-wise KPIs for Adidas retail data.

### 🔹 Amazon Sales Analysis  
E-commerce sales patterns, profit metrics, category performance.

### 🔹 Bike Sales Analysis  
Customer segmentation, purchase trends, and sales forecasting.

### 🔹 Car Sales Analysis  
Insights on car model performance, profitability, and customer demographics.

### 🔹 Coffee Shop Sales  
Footfall analysis, product performance, daily/hourly sales trends.

### 🔹 Electric Vehicle Sales  
EV adoption trends, top manufacturers, and growth analytics.

### 🔹 HR Analytics Dashboard  
Employee attrition, department-level metrics, satisfaction analysis.

### 🔹 Madhav E-commerce Store  
Sales KPIs, category breakdown, customer behavior insights.

### 🔹 Pizza Sales Dashboard  
Best-selling pizzas, revenue patterns, daily/weekly trends.

### 🔹 Road Accident Analysis  
Accident hotspots, vehicle types, severity and time-based patterns.

### 🔹 Sales & Profit Analysis  
Insights into profitability, discount effect, and top-performing segments.

### 🔹 Super Store Sales Analysis  
Category performance, regional profit, customer trends.

### 🔹 Vrinda Store Analysis  
Store performance dashboard with growth and demand metrics.

### 🔹 E-commerce Sales Analysis  
Comprehensive dashboard covering orders, revenue, and customer patterns.

## 🔧 Skills Demonstrated  
- Data Modelling (Star Schema)  
- Measures using **DAX**  
- Power Query Transformations  
- Interactive Dashboards  
- KPI Cards, Maps, Bookmarks, Slicers  
- Insight storytelling & design principles
