
# 📞 Call Center Performance Dashboard – Power BI Project

## 📊 Project Overview
This Power BI dashboard provides a complete analysis of call center performance, including call volume, duration, SLA compliance, customer sentiment, call reasons, channels, and geographic distribution.

The report contains **two pages**:
1. **Home View** – Interactive charts & KPIs  
2. **Grid View** – Full call-level data table for detailed review  

---

# 🚀 Key Features
- KPI cards showing total calls, average duration, SLA %  
- Dynamic slicers for Date, City, Channel  
- Visual navigation buttons (Home | Grid)  
- Trend analysis, sentiment insights, and call reason breakdown  
- Detailed call records with SLA classification  

---

## 🔹 **1. Home View – Summary Dashboard**

### **📊 Visuals Included**
- Total Calls by Day  
- Calls by Reason (Tree Map)  
- Calls by Sentiment  
- Total Calls by State (Map)  
- Calls by Channel (Donut Chart)  
- Calls by Call-Center City (Bar Chart)  

---

## 🔹 **2. Grid View – Detailed Call Table**

Contains full call-level data, including:
- Caller ID  
- City  
- Customer Name  
- Channel  
- State  
- Call Duration (in minutes)  
- SLA Category: Within, Above, Below SLA  
- Reason for Call  

This page is ideal for:
- Quality checks  
- SLA monitoring  
- Investigating long calls  
- Tracking customer issues  

---

# 📊 Insights Summary

### ✔ Call Volume Trends
- Friday and Thursday have the highest call loads.  
- Weekends show lower volume.

### ✔ Call Reasons
- **Billing Question** is the most common reason (23.5K calls).  
- Payments and Service Outage follow.

### ✔ Sentiment Breakdown
- Majority of interactions are **Negative** or **Neutral**.  
- Very Positive sentiment is the least common.

### ✔ Channel Usage
- Call Center (voice) = **32%** – Most used channel  
- Chatbot (25%), Email (23%), Web (20%)

### ✔ Geographic Insights
- Highest call activity from major U.S. cities such as:
  - Los Angeles  
  - Baltimore  
  - Chicago  
  - Denver  

### ✔ SLA Performance
- 75.3% of calls handled within SLA target.  
- Remaining calls (Above/Below SLA) indicate improvement opportunities.
